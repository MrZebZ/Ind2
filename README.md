**Hidden SnR** is an advanced psychological Support and Resistance indicator for TradingView. Instead of relying on historical price pivots, it identifies potential reversal zones based on mathematical and psychological number patterns in the asset's price.

## ✨ Key Features
- **Round Levels:** Standard psychological round numbers.
- **Similarity Patterns:** Repeating digits (e.g., 1.111, 2.222).
- **Increment/Decrement:** Sequential upward or downward steps (e.g., 1.234, 4.321).
- **Arithmetic Sequences:** Addition, Subtraction, Multiplication, and Division alignments between digits.
- **Mirror Patterns:** Palindromic and mirrored digit sequences.

## 🛠️ Installation
1. Copy the source code from `src/hidden_snr.pine`.
2. Open TradingView, go to **Pine Editor**.
3. Paste code, save, and click **Add to Chart**.
